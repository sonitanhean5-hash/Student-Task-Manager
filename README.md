# Student Task Management System

Web app that helps students create, track and complete their academic tasks.

## Status

M1 frontend prototype: Vue 3 + TypeScript on mock data. The NestJS API and PostgreSQL arrive in M2.

## Run it locally

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run lint
npm run build      # type-check + production build
```

## Layout

- `web/` Vue 3 app (Vite, Vue Router, Pinia)
- `docs/` wireframes
- `MILESTONES.md` checklist and design answers
